# R2 受控实验结果

## 同初解与真实交换

四设计使用相同 Stage 1 快照时，A6 与 A0 的合计固定目标分别为 10718456.272 和 10719587.685，Stage 2 实际合计耗时分别为 120.220 与 83.071 秒。两者使用相同名义子预算，实际耗时差异保留。组再生成在 ethmac 的两个真实跨裸片网之间发现可复算的 HBT 交换，独立验证的固定目标下降 2.1625。该交换也在端到端试跑重现，Stage 3 后两网站点指派保持。BP 的计数也出现一次严格双网接受，限长案例列表未保留其逐边证据。

## 剖析和详细检查

四例插桩下，V3 与 A6 的 Stage 2 分别为 88.753 与 120.245 秒，主问题求解包含时间为 3.051 与 7.420 秒。A6 档案计时约 0.847 秒，组再生成约 3.505 秒，交换提交约 0.077 秒。函数计时可能包含子模块时长，进程墙钟始终单独保留。Profile 为诊断产物。

正式详细验证使用第一轮全局布线产物。旧 V3 的新跑基准与 A7 新跑各具有独立 Guide、派生 DEF、OpenDB 几何导出及联合导体证据。缺失的行保留 N/A。

## 可选筛选与预算对照

四设计单次消融中，A6 安全支配删除 1,542 个候选，墙钟合计 364.920 秒。关闭支配的 A6-no-dominance 为 353.341 秒，固定目标 10700968.859。开启轮转的 A6-rotation 为 361.151 秒，固定目标 10702526.037。三配置均发现两次严格双网接受。这些限时结果同时反映候选保留与搜索进度。严格支配的安全性由完整有限池算例验证。本轮测量没有支持其作为速度优化启用。

预算实验共 56 轮，含两版本各七个无额外预算样本。42 个有上限样本中，V3 达标 9/21，R2 联合配置达标 10/21。23 个超额样本保留完整物理回放，并显式标记 BUDGET_UNMET。该标记表示当前候选及时间范围未满足要求。理论上，跨裸片真实终端网数是 HBT 必要下界，超额样本自身没有建立更强下界。四类预算图仅绘入通过对应验证的样本。
