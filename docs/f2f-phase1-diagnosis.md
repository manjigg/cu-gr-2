# F2F 第三节诊断

基线为 `one-3d-change-from-2d-baseline` 的 `991dd4b`。开始时当前分支 `two-3d-change-from-2d-baseline` 与其同一提交。单 Die 源码参照 `2d-baseline` 的 `8393419`，论文复现参照 `h3d-dp` 的 `f806117`。

## 调用链与边界

| 位置 | 原实现及审计结论 |
|---|---|
| `F2fRouter.h/runF2f`、`Design.cpp/Design,extract`、`GlobalRouter.cpp` | F2F 用独立 Rsyn 上下文装载两份 LEF/DEF、保留局部名称空间、两套 GridGraph。原单 Die 入口及 Guide 格式仍由 GlobalRouter 支持。 |
| `GRNet.h`、`buildJobs()` | 用两侧同名切分端口和实际 DEF NETS 连接或显式表建立跨 Die 任务。移除的只有确认过的切分端口。普通 PORT 和实例 Pin 保留。接入点来自该 Die 的真实 Pin 几何。 |
| `projectSteiner()`、`medianRegion()` | 取每 Pin 的首个 G-cell 中心，转封装 DBU，重复投影坐标保留 Pin/Die 标签。FLUTE 返回二维树，单 HBT 的中位区间最小化星形端点 L1 和；该指标无法代替布线树长。接入点、金属层、容量和 Via 都可能改变实际路径。 |
| `labelTopology()` | 固定投影树上做二状态 Die 分配。跨父子边或节点处出现对侧 Pin 时引入 HBT；权重 1/3 只给两组解，等分保留同 Die，不会为各个 HBT 数量分别保留最优构型。 |
| `F2fGraph::candidates()`、`planJob()` | 原版 R-tree 选区域与近邻，按到框 L1 距离和站点编号排序；首次 8、重布 20 个。多 HBT 的第 r 组从每个锚点的第 r 个站点开始，至多 3/6 组，遗漏不同排名的交叉组合。HBT 每站容量 1。 |
| `evaluateTopology()`、`PatternRoute.cpp/.h` | 根据拓扑拆出局部分量，把落点加入对应分量的 Pin，再运行局部 FLUTE、L 形候选 DAG 和合法 Via 层分配。Stage 2 的绕行视图是阶段级快照。HBT 由外层预选。 |
| `routeLayeredMaze()`、`MazeRoute.cpp/.h` | `2d-baseline` 的 Maze 先走 H/V 方向平面，再由 Pattern 分配真实层。现版 F2F 的局部 Maze 已用真实层及合法 Via，采样步长/边界分级，HBT 仍以所选落点作为分量端点。 |
| `getForestCost()`、`commitForest()` | 多分量会按 Wire/Via 的单位资源去重；一个分量时走按树逐段提交/计价旧路径，可能重复经过同一物理边。Via 的最小面积估计另以分数需求占用相邻导线边。 |
| `routeJobs()` | 依次 Pattern、Detour、Maze，后两阶段按含 Via 足迹的资源溢出挑网。先释放旧树与可移动 HBT；只要新方案可生成即提交，没有将其与旧方案在相同剩余资源下重新比较。 |

## 修改算法前的测量

通过可选 JSONL 对每个网记录 Pin/Die、投影 RSMT、候选数、实际候选成本（含分项）、候选不足、每阶段站点、旧/新方案及两侧线长和溢出。重复边统计按单位 Wire 和 Via 展开，原版提交口径保持。新增诊断不会改变旧搜索。

- AES 的两份 Guide 和 HBT TSV 对比原批次逐字节相同。实际为 137,447.1 µm、90,718 个 Via、388 个 HBT；三阶段线长相同，Stage 2/3 完全未重布。跨 Die 网的 Stage 1 路由长 23,272.2 µm，投影骨架长 20,846.7 µm，差值 2,425.5 µm。该差值同时包含双 Die 展开、站点离散、局部拓扑和实际接入，无法拆成单一原因。
- AES 有 24 条网曾评估同数量、更短的站点方案（累计长度差 71.4 µm），有 16 条网评估过多一颗 HBT 且更短的方案（79.8 µm）。这些替代方案在综合代价下落败。不能把较短的局部几何直接当成更优的整网结果；例如 `_12477_` 的两站点候选短 10.5 µm，综合代价约 372.16，所选单站点为 359.12。当前比较可见候选，无法用其估计未搜索方案的收益。
- AES 首阶段统计到 29.4 µm 的重复遍历和 6 个重复 Via，两个数字包含原多分量已去重的项，不能全当成原结果虚增。从规模看，这个可观察重复量远小于跨 Die 投影与实际树的差距。
- 100 网人工拥塞用例的 Stage 1/2/3 线长为 15,943.2 / 16,308.6 / 16,751.7 µm，导线溢出为 1,824 / 15 / 0。长度随消除拥塞而增加。在同一外部资源占用下，旧策略的 Stage 2 有两条网接受了重新估价后更贵的方案；这两条是否值得换还取决于溢出改善，不能按代价差单独判断。
- `Design::setUnitCosts()` 已将长度归一到各 Die M2 pitch 并乘权重，Via/HBT 为费用；累计物理线长用各 Die DBU 转换。七组实验两侧使用相同工艺。未观察到足以解释这些线长差的 DBU 换算错误。Via 脚印需求的长度截断属于现有成本模型，诊断保留该口径。

## 依据

H3D 第 III-B/III-C 的固定拓扑 Die 标签及 L1 连续最优区域适合缩小搜索；本文的候选搜索未复现论文完整离散 DP。FLUTE 保持二维内核，EDGE/CUGR 的连接 DAG 和局部层分配保持既有局部求解职责。详细布线旧结果与全局线长属于不同测量层级。历史 H3D 复现结果也使用不同资源/对齐设定，需在站点、约束、真实终端对齐后再作可归因的定量比较。
