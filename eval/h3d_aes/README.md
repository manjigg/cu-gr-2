# AES 真实输入验证

原始输入保留在 `benchmarks/h3d_aes/`。每次实验创建独立的 `run_*` 子目录，
其中保存输入哈希、派生 LEF/配置、实际命令、进程退出状态、日志和验证报告。
目录中的阶段性结果不能自动解释为完整 AES 路由成功或详细布线/DRC 通过。

**已完成源规格分支全量验证：[`run_007/REPORT.md`](run_007/REPORT.md)**。
沿原服务器路径找到真实 `.input/.txt/DEF/LEF`，重建的网表、放置及库文件与原提供内容逐字节相同。
实际终端模型是 1 µm 尺寸＋1 µm 间隔；据此构造 2 µm 阵列并使用真实模型的 1 µm pad，论文八方向、单次回溯完成全部 14310 网，两个 die 均零溢出。
这修正了源模型适配，**不代表原 3 µm/1764 点实验已修通**；新旧输入与证据均独立保存。

**最新根因定位：[`run_006/REPORT.md`](run_006/REPORT.md)**。
同森林、同种子仅取消八方向裁剪仍失败，证明改回全域不解决站点耗尽；同数据同 3 µm 的历史完整解再次验证通过。
源参数审计发现 3 µm 是转换脚本的研究假设，原始 placer `.input` 未随包提供。
严格论文步骤的 2 µm 对照已全量通过，但原 3 µm 条件仍未修好，两个结论分别保存。
